# 八字四柱完整推算（排盘实操）— 整书理解

## 主旨

系统性掌握八字命理推盘方法，从排四柱→分析刑冲合害→判断旺衰格局→取用神忌神→实战解读，覆盖八字分析全部核心知识点。

## 骨架（结构）

### 第一层：排盘基础
- 年柱：以立春换年
- 月柱：以十二节令换月，五虎遁推月干
- 日柱：查万年历，23点后算次一日
- 时柱：五鼠遁推时干

### 第二层：分析工具（刑冲合害）
- 天干五合（5种）
- 地支六合（6组）
- 地支六冲（6组）
- 地支六穿（6组）
- 地支相刑（4组）
- 地支三合局（4组）
- 地支三会局（4组）
- 地支半合局（8组）

### 第三层：十神体系
- 十神定义（五行生克+阴阳）
- 十神组合象法（14种核心组合）

### 第四层：核心判断
- 旺衰三要素（得令、得地、得势）
- 五行生克制化（生克泄耗制化）
- 格局定性（月令提纲）

### 第五层：实战解读
- 喜忌取用
- 大运排法与解读
- 性格、事业、婚姻、健康、六亲

## 批判性分析

### 优势
1. 体系完整：覆盖排盘→分析→判断→解读全流程
2. 实操性强：口诀清晰（如五虎遁、五鼠遁）
3. 组合丰富：14种十神组合象法直接对应实战

### 局限
1. 旺衰判断只给框架，具体细节需配合实战经验
2. 大运排盘男女顺逆规则分散，未集中强调
3. 材料未覆盖"从格"特殊情况的详细判断

## 应用方向

用户输入"测一下这个人的八字"或"排一下这个人的八字"时，本套 skills 通过以下流程完成一次完整推盘：
1. 排盘基础 → 获取四柱
2. 天干地支分析 → 原局核心组合
3. 旺衰格局判断 → 喜忌取用
4. 十二模块输出 → 完整解读报告

## 第二本书：事业择业方法论（seg2）

### 主旨

在已有推盘体系之上，回答「这个命局该做什么行业、什么打法、什么时候动手」。

### 骨架

- **五行择业**（资料1）：五行核心象义 → 代表职业 → 性格适配 → 方位；复合行业叠加
- **格局择业**（资料2）：十正八格 + 七组经典配格 → 行业定向；成格/破格与三条心法
- **调候择业**（资料3）：六大气机 → 主药/次药 → 药的真假 → 生机赛道 → 三种择业策略
- **大运流年择业**（资料4）：原局→大运→流年三层；大运三策略；流年出手与宜守信号

### 与第一本书的关系

第一本书产出「命盘是什么」，第二本书产出「命盘意味着该怎么做」。
第二本书的调候部分是第一本书完全没有的增量。

### 应用方向

用户问「适合做什么行业」「什么时候适合创业」时，`shiye-master` 按
`调候 → 格局 → 五行 → 岁运` 的顺序推进，输出符合 `docs/CAREER_SCHEMA.md` 的事业方案。
