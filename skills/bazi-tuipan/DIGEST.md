## 一、排盘基础（四大规则）

| 规则 | 要点 |
|---|---|
| 年柱 | 以**立春**换年，非正月初一 |
| 月柱 | 以**十二节令**换月，非农历初一 |
| 日柱 | **23点**后算次一日，非午夜12点 |
| 时柱 | 用**真太阳时**，跨时区需校正 |

### 五虎遁（年干→月干）

```
甲己之年丙作首，乙庚之岁戊为头
丙辛必定寻庚起，丁壬壬寅顺水流
戊癸何方发，甲寅之上好追求
```

### 五鼠遁（日干→时干）

```
甲己还加甲（子时=甲子）
乙庚丙作初（子时=丙子）
丙辛从戊起（子时=戊子）
丁壬庚子居（子时=庚子）
戊癸何方发，壬子是真途（子时=壬子）
```

## 四、旺衰三要素

| 要素 | 权重 | 内容 |
|---|---|---|
| 得令 | **最大** | 月令五行对日主的生克助力 |
| 得地 | 其次 | 地支通根（本气根/中气根/余气根/无根） |
| 得势 | 最后 | 天干印比帮身的配比 |

**综合定论**：身旺/身弱/中和/从格

## 八、事业择业链（seg2）

### 四层叠加

```
调候定药  ·  格局定底盘  ·  五行定赛道载体  ·  岁运定时间表
```

> 四层是**职责分工**，不是执行先后 —— 输出键序见 `docs/CAREER_SCHEMA.md`（`pattern` 在 `tiaoHou` 之前）。

### 调候六气机（主药 / 次药）

| 气机 | 主药 | 次药 |
|---|---|---|
| 寒局 | 火 | 燥土 |
| 燥热局 | 水 | 柔金 |
| 湿重局 | 燥土 | 火烘干 |
| 燥硬局 | 清水 | 柔金打磨 |
| 春木旺局 | 金修剪 | 火暖成材 |
| 秋金肃局 | 火淬炼 | 水淘洗 |

### 药的三态 → 择业强度

| 药 | 判据 | 策略 |
|---|---|---|
| 真药 | 透干、有根、不被合克墓藏 | 主业重仓 |
| 藏药 | 藏在库、拱、暗合 | 底盘待机 |
| 假药 | 虚浮无根、被合被克埋死 | 守成缓投 |

### 格局一句话

> 正财守底盘，偏财抓风口。正官顺梯而上，七杀闯关夺旗。正印大道传经典，偏印深山藏绝活。食神养人留余味，伤官破局立新天。比肩结伴铺大路，劫财冲锋抢地盘。

### 岁运三策略

顺势重仓 / 轻试待机 / 守势收缩 —— 与调候三策略同构。

### 四条心法

1. 缺但为忌，补了反而压力大
2. 五行只是载体，能不能「出功」才是根本
3. 一个好流年落在坏大运里，往往是诱饵
4. 不要把「引动」等于「稳成」—— 命理只是时机参考，不是保证书
